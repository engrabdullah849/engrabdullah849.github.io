# Muhammad Abdullah — Mechanical Design Engineer Portfolio

GitHub Pages portfolio for Muhammad Abdullah.

## Deploy
1. Create a public repository named `engrabdullah849.github.io`.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages** and deploy from the `main` branch and `/ (root)`.
4. Your site will be available at `https://engrabdullah849.github.io/`.

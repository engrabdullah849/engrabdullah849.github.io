# Muhammad Abdullah — PDF-Matched GitHub Portfolio

This version is intentionally built from the exact 13-page `Mechanical-Design-Portfolio.pdf`.

The website displays each PDF page as a full-width image, preserving the same layout, typography, colors, spacing, project images, and page composition instead of recreating the design with different HTML/CSS.

Interactive areas are preserved on:
- Page 1: PDF download, View Projects, Contact Me, and the top navigation.
- Page 13: Email, WhatsApp, LinkedIn, and PDF download.
